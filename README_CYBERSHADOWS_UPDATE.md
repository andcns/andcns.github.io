# CyberShadows case-study update

This patch is designed for the current portfolio structure used on 2026-09-04.

## Add / replace

- Replace `index.html`
- Add `cybershadows.css`
- Add `content/cybershadows.js`
- Add the whole `assets/images/cybershadows/` folder

No changes are required to `styles.css`, `site.js`, `content/portfolio.js`, or the existing Winterlight files.

Devlog No. 1 / 28 October 2026

A seeded 8 × 8 board now generates branching roads, clustered terrain, buildings and a river with an occasional bridge. This first milestone is about making those systems work together reliably.

Routes that actually connect

The road generator builds a main route with branches that split and rejoin. Connections are stored as gameplay data, not inferred from the meshes. Each seed changes the layout while keeping a valid route from start to finish.

An environment that follows the board

A separate Blueprint builds terrain variation, tree clusters, buildings and a continuous river around the generated paths. Artist-facing controls manage spacing, density and scale without changing the road network.

Making regeneration reliable

The most useful fixes came from rebuilding: overlapping terrain tiles, rotated bridges and excessive Blueprint loops. I separated generation IDs from random seeds, kept tile indices stable and replaced repeated distance scans with local neighbour checks. Repeating a seed now reproduces the same board.

Next milestone: a playable journey

The current Kenney assets are placeholders for a Romanian countryside kit. Next comes a complete run with route choices, dialogue, resources and a folklore puzzle. My focus remains PCG, environment art and technical art; Abi and Robert own gameplay programming, and Vlad leads audio.
